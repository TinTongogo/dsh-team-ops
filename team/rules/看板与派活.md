## §二 4c：发不出去 / 只增不减的细则

   真发不出去时先看原因（服务不在 / 目标名不对 / 队伍没成队），**别急着新建一位** —— 同角色上限拦得住，
   但那是在浪费一个**角色槽位**。原生名册没有"归档 / 退役 / 删除"这几档：不用的队友不再派活即可，
   名字在名册里永久占位（**原生名册行谁也腾不了** —— 要一份干净名册只能开新会话，见 4b 那三个词）。

## §五 7："说了没派"的现场与理由（task-78）

**现场（五次）**：另一个会话里的 lead 在**长回复**里把"我打算派"写成了"我派了" ——
①「我这就派 reviewer 复核」②「我批它落 02」+「我派 data-eng」③「我把名单转给 architect」
④「我这就派它落」⑤「补读数和落册我一起派」——**五次都没发**。

**为什么不是代码问题**（三条证据）：
1. 我们的派活路径**诚实**：`team/native-layer.js` 的 `sendToTeammate()` **只有真调过宿主 `service.sendMessage` 并 await 成功**
   才返回 `{ok:true}`；服务 / 方法缺失、抛错一律 `{ok:false, reason}` ⇒ **没有"静默成功"**；
2. 宿主**不会**"截断时保留文字、丢弃工具调用"：它有 `stop_reason` / `max_tokens` / 截断提示那套机制，**但没有**那条路径；
3. ⇒ **根因是序列 + 自述**：调用被排在**长总结之后**，总结一写完回合就结束了（被输出上限掐断时更甚），
   而**文字里已经写了"我派了"** ⇒ 人看到的就是"说了没做"。

**为什么用"凭据"而不是"提醒自己记住"**：`notified` 与任务号**只在回执里有** ⇒
**说不出这两个就是没派**，这是**可当场核的自我否证**；"reassign 不能省"则把兜底放在机制上
（它**同时**把卡推进「进行中」并**自动按门铃**，于是**漏发消息也不致空转**）。

**本单没做（等协调器问人）**：`Stop` 钩子式机械兜底（回合结束后扫 assistant 文本里有没有"我派了"而无对应派活调用 ⇒ 追加一行警告）——
技术上可行（我们已用 `SessionStart` / `UserPromptSubmit` 两个钩子，`Stop` 在宿主事件集里），
但**每回合都要跑**，且**警告只是文字**（不能替人重放调用）。

## §五 8：回报默认落看板不落人（HD-011 现场）

**人的原话**：「插件现在有点啰嗦，团队内同时多成员回复给 lead 时，如果不需要人裁决，不需要把消息再复述一遍到对话中，
自行指派任务并把任务落到任务看板。只有需要人裁决时再让人决策，同时把问题简要描述清楚。」

**现状为什么会啰嗦**：成员回报后协调器把成员的话**再转述一遍给人** —— 人读到的是"二手复述"，
而真正要看的（产物、状态）在产物与看板上都能读到；多成员同时回报时更明显。

**这一条与相邻两条的分工（别混）**：

| 纪律 | 管什么方向 | 说什么 |
| --- | --- | --- |
| **回报默认落看板，不落人** | **协调器 → 人** | 不需要人裁决的**不把人拉进来**（直接落看板条目）；要人裁决的才一条说清 |
| 回报只放指针（第一行就是指针） | **成员 → 协调器** | 成员回报只给产物路径 + 一句话，长内容落文件 |
| §八「精确、不拖泥带水、不绕弯子」 | **对外输出的默认层级** | 这条是它的**具体化**，不是另一套要求 |

## §五 9–11："状态与事实分家"这一类（task-80）

**人的话**：「**"状态"与"事实"分家的那类问题还是没解决，总是出现**」。

**根因（这一类为什么必复发）**：**同一个事实存在两处，而两处之间没有机械对齐** ⇒ 只能靠"人记得同步"。
**已发生的实例**（都真出现过）：① 改了归属却没叫醒人（账上说"派了"、事实是"没动"）；② 卡停在「待办」而活已干完；
③ 说了没派（文字状态 vs 调用事实）；④「停用不占角色槽位」的措辞 vs 宿主按 `state.members.length` 数全部名册行；
⑤ **交接快照印「进行中 N 条 / 待办 N 条」，而实时板面是空的**；⑥「两处一致」的断言是假绿（只钉了子串）；
⑦ 汇报说"已提交"却漏了 `package.json`。

**已经机检、不再复发的两类**：BASELINE ↔ 注入策略段的"两处一致性"清单；三词术语断言。

**三条修法**：A 凡宣称状态必带凭据（命令 + 输出 / 路径 + 关键行，且带时间；写不出凭据 = 不许宣称）；
B **同一事实不许两处并存** —— 要并存就**必须配一条机械检查**，写不出检查就删到一处或改成派生（本单根治的一条）；
C **派生读数不得当状态** —— 交接快照去掉裸计数、块首标 `**快照@<时刻>**` + `**非实时**`、列"当时未完成"的条目。

**C 的机械检查落在哪**：`lib/ledger-digest.js` 的 `handoffLine()`（渲染侧）+
`tests/team-ops.test.mjs` 里那条交接快照用例（断言块首标记、断言**不出现**裸计数）。
